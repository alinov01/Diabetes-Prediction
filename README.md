# Diabetes Prediction using Machine Learning

Predicts whether a person is diabetic based on medical data using Support Vector Machine (SVM).

## Algorithm
- Support Vector Machine (SVM) with linear kernel

## Libraries
- NumPy, Pandas, Scikit-learn

## Dataset
- PIMA Indians Diabetes Dataset (768 samples, 8 features)

## Accuracy
- Training: 78.6%
- Test: 77.3%

## How to Run
1. Clone the repo
2. Install: `pip install numpy pandas scikit-learn`
3. Open notebook in VS Code
4. Run all cells
